**Carnegie Mellon University Dietrich Computing & Operations** builds open-source tools for research and teaching.

## DARE

The Dietrich Analysis Research Education (DARE) Platform: AI chat, document search, research workflows and usage tracking for universities and non-profits.

| Repository | What it is |
| --- | --- |
| [dare-backend](https://github.com/cmudco/dare-backend) | Django API: accounts, chat, documents, retrieval and billing |
| [dare-frontend](https://github.com/cmudco/dare-frontend) | React web app and documentation site |

Both are licensed under AGPL-3.0. To get started, see each repository's README.
